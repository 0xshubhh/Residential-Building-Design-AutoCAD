# Residential Building Design | AutoCAD

## 📌 Project Overview

This project presents the architectural planning and drafting of a residential building using AutoCAD. The drawing includes a detailed floor plan, front elevation, and sectional view, along with an area statement and door/window schedule.

## 🏠 Project Components

- Detailed Residential Floor Plan
- Front Elevation
- A–B Section
- Area Statement
- Door and Window Schedule
- Architectural Dimensioning

## 🏗️ Spaces Included

- Living Area
- Dining Area
- Kitchen
- 2 Bedrooms
- 2 Bathrooms
- Verandah / Sit-Out

## 🛠️ Software Used

**AutoCAD**
